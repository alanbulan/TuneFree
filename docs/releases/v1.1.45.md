# TuneFree v1.1.45

## 新增

- 歌单预览支持跨页歌曲多选、本页全选、选择全部、清空选择，以及播放所选和导入所选。
- 点击预览中的歌曲或播放全部时，会将完整歌单放入当前播放队列，从所点歌曲或第一首开始，与本地歌单保持一致。
- 读取完整歌单可取消，弹窗内缓存元数据；显示仍按每页 20 首和共享虚拟化歌曲列表进行。

## 修复与优化

- 修复 QQ 登录后缺失头像，按官网本人资料字段补查并保存，重启可恢复；酷我头像和昵称逐个解码、验证后回退。
- macOS 将三平台会话与模型密钥合入一个系统凭据项，共享进程内读取与失败缓存，减少启动时分平台重复授权；旧记录按需迁移并验证保存。
- QQ 官方账号解析统一音乐身份与会话参数，兼容当前 media MID 文件名和既有候选，按平台授予的完整播放权限选择实际音质。
- 选择性导入复用同名确认，失败重试保留原选择；关闭、取消或切换账号后旧响应不能改队列或曲库。
- 删除账号页重复实现说明，复用既有歌曲选择、按钮与分页样式；最小窗口下歌曲区域滚动，预览底部导入按钮完整可见。

## 验证

- 1,086 项前端测试，100% 行覆盖率；17 项浏览器回归；macOS 318 项 Rust 测试、严格 Clippy、原生 release 构建与隔离启动通过。
- 本人 QQ 头像保存及重启恢复、官方账号 128K 实播已观察；网易歌单选择两首播放和完整队列播放已观察。
- 标签发布沿用共享 Windows / macOS CI、通用双架构构建与启动、更新签名及六项资产 / 更新清单检查。

酷我本人账号与会员高音质未实测。当前 macOS 使用 ad-hoc 应用签名，跨版本系统凭据授权仍由 macOS 决定；统一读取不会绕过系统授权。
