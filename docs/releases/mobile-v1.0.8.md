# TuneFree Mobile v1.0.8

Android 移动端新增自定义音源管理，升级 Flutter、依赖和 Android 工程，并修复 Release 包的系统媒体控制。

## 新功能与优化

- 「我的」新增独立「音源」页签，音乐接口与歌单接口分别管理；卡片、输入框、连接方式和检测反馈跟随现有主题、深色模式与强调色。
- 音乐接口支持 GD 签名 POST 与 api.php 兼容 GET，保留服务地址的路径和查询参数；GD 签名自动校准服务器时间。
- 自定义音乐接口用于搜索、播放、歌词、封面和下载。切换音源后，队列与收藏歌曲重播、新下载使用当前配置和音质；有效离线文件继续优先播放。
- 歌单接口支持 TuneHub 兼容协议，平台直连导入失败时提供补充。
- 连接检测使用当前草稿；保存后立即生效并在重启后保留，支持一键恢复默认。
- Android 17 的局域网服务接入本地网络授权，拒绝后提供重试与系统设置提示。
- 修复 Release 资源压缩导致通知栏播放／暂停等媒体控制图标丢失的问题。
- Android 更新检查按 APK 筛选稳定移动版本，兼容旧标签与新的 `mobile-v*` 标签。

## 工程升级

Flutter 3.50.0 / Dart 3.14.0；Android Gradle Plugin 9.5.1、Gradle 9.9.1、Kotlin 2.4.21；Android SDK 37.2、targetSdk 37、Build Tools 37.0.0、NDK 30.0.16248370。所有直接 Dart 依赖升级到本次核验的最新稳定版本，受 SDK 或上游约束的间接依赖保留最新兼容版本。

## 安装与使用

下载附件 `tunefree-1.0.8.apk`，支持 Android 7.0 及以上，包含 ARM64、ARMv7 与 x86_64。正式包沿用原发布签名，版本号 1.0.8、构建号 9，可覆盖安装上一版 1.0.7。

打开「我的」→「音源」，填写接口地址和连接方式，检测后保存。局域网服务在 Android 17 上需要允许本地网络访问。

音乐服务需兼容 GD / api.php，歌单服务需兼容 TuneHub；首页榜单继续由各音乐平台提供。第三方默认音乐服务存在间歇性 HTTP 503，遇到时可稍后重试或使用可用的兼容服务。桌面 JavaScript 音源脚本暂不在移动端执行。

## 验证

完整 Flutter 自动测试、golden 检查、静态分析与构建信息检查通过；Android 16 和 Android 17／16 KB 模拟器完成自定义接口切换、保存恢复、搜索、播放、歌词、下载及媒体控制验证。Android Debug／Release、Web 与 iOS 模拟器构建通过；本次发布提供 Android APK。
