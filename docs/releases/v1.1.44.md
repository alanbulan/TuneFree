# TuneFree v1.1.44

## 新增

- 支持网易云音乐、QQ 音乐、酷我音乐账号登录，官方窗口完成登录后将会话保存在本机系统凭据存储。
- 播放对应平台歌曲时优先使用本人账号取链接，无需安装音乐脚本。播放器在播放开始后显示账号来源与实际音质，可播放范围按账号权益。
- 个人歌单每页 10 个，支持跨页多选、全选、批量导入、停止与失败重试。
- 歌单预览弹窗每页 20 首，支持单曲播放、播放本页、暂停 / 继续、收藏和整份导入。

## 优化与修复

- 平台下拉和刷新按钮统一为 128 × 32px，复用项目选择器、按钮、分页、弹窗和歌曲表格，移除浏览器默认深色边框。
- QQ 登录弹窗保留官网回调所需的 opener 和 Cookie 环境，酷我指定 HTTP 登录回调升级 HTTPS。
- 登录、退出、重新登录和账号失效会更新播放缓存，预加载、暂停恢复、换队列与循环不复用旧账号链接。
- 修复被遮挡的 macOS WebView 暂停动画帧时，启动检查等待界面就绪通知的问题。

## 验证

- 2026-11-15 持有人完成开发模式验收并反馈「可以了，没问题了」，授权按原 GitHub Actions 流程升级与发布。
- 功能提交 CI：1,075 项前端测试，行覆盖率 100%；15 项浏览器回归；macOS 291 项、Windows 355 项 Rust 测试，以及两平台原生构建和隔离启动通过。
- 发布标签另执行共享质量检查、Windows 安装包与 macOS 通用包构建、更新签名和六项资产 / 更新清单完整性检查。

浏览器播放回归使用模拟 IPC 与测试音频。持有人验收反馈不扩写为逐平台、逐会员音质或 Windows 登录的独立实测结论。
