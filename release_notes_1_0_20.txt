本次更新带来了主题切换便捷度与深色模式的深度完善：

1. **顶栏新增快捷主题切换按钮**
   - 在主窗口顶栏（TuneFree 标题右侧，搜索框左侧）全新添加了“主题快速切换按钮”组件；
   - 与全局 `ThemeContext` 的 `themeMode` 双向绑定，可显示当前状态（浅色 / 深色 / 随系统）及对应的系统矢量图标（Sun / Moon / Laptop）；
   - 支持一键循环快速切换主题模式，省去了前往管理设置页面的繁琐步骤，大幅提升了操作体验。

2. **全面自检与补全深色模式漏网组件**
   - 彻底排查并对所有在深色模式下可能残留白底、亮影或投影的全局组件进行了 CSS 样式覆盖：
     * 重构并微调了设置主卡片（`.stat-card`）、卡片 Hover 态（`.create-card:hover` / `.toplist-card.active`）的背景与阴影，在深色模式下完全回落为高雅的暗夜底色；
     * 为“主题快速切换按钮”定制了专用的深色模式拟玻璃磨砂质感与强调色发光悬停动效；
     * 补全了关于声明卡片（`.about-notice-card`）、输入框聚焦态等在深色模式下的底色，确保主程序和全屏播放器的暗黑一致性体验达到 100% 完美覆盖。
