本次更新重点修复了关于页面及更新检测机制，并正式合入了系列体验优化与深色模式适配：

1. **发布与更新机制修复**
   - 修复了此前打包因 GitHub Release 草稿状态且未附带安装包资产，导致客户端检测更新时卡在 v1.0.18 的问题。重新整理了编译发布管线，确保客户端可一键无缝更新。

2. **桌面歌词体验大幅升级**
   - **硬描边优化**：移除了文字边缘的大模糊发光（Blur）效果，换用锐利硬边缘黑色描边，字体边缘更清晰，杜绝文字削顶、削底裁剪现象。
   - **矢量化锁图标**：锁定/解锁状态指示弃用 emoji 🔒，统一改用系统内置的 Lucide 矢量图标，UI 风格更加精美和专业。
   - **智能上下文歌词**：支持自适应高度展示完整的上下文滚动歌词，打破单行/双行局限，无论窗口高度如何调整，当前播放行始终磁吸居中对齐。
   - **强调色同步**：完美解决了 Tauri 子窗口进程中 CSS 变量隔离问题，桌面歌词颜色与主窗口强调色及暗黑/明亮模式实现 100% 动态实时同步。

3. **顶栏新增快捷主题切换按钮**
   - 在主窗口顶栏（TuneFree 标题右侧）全新添加了“主题快速切换按钮”组件，与全局 Theme 状态双向绑定。可循环切换（浅色/深色/随系统），免去进入设置页的繁琐步骤。

4. **全面适配暗黑/深色模式**
   - 彻底排查并对全屏播放器背景、队列卡片、设置主卡片、关于声明卡片等在深色模式下可能残留白底或白影的组件进行了全面的 CSS 暗黑样式覆盖，保证 100% 一致的深色模式体验。
