本次更新带来了深度优化，主要针对桌面歌词裁剪、跨窗口交互以及全屏播放器的深色模式支持：

1. **解决歌词文字削顶/削底截断问题**
   - 彻底重构了桌面歌词行的 CSS 盒模型，去除了外层 div 容器在垂直方向的 `overflow: 'hidden'` 限制，允许溢出的阴影和描边正常渲染；
   - 限制文字水平超长裁剪行为仅发生在内部 span 节点，并增大高亮行 padding 垂直填充至 `10px 0`，同时提高 `lineHeight` 到 `1.5`，确保大字号文字及其 1.5px 的硬黑色描边在任何屏幕比例下都不会被发生任何上下边缘截断，显示极度饱满锐利。

2. **桌面歌词高亮颜色完美同步软件主题色**
   - 在桌面歌词独立窗口（独立的渲染进程）中，新增了对 `tunefree_theme_color` 与 `tunefree_theme_mode` 的初始化读取和定时检测；
   - 自动根据当前的强调色和跟随系统的暗黑/明亮状态，计算并为桌面歌词窗口的 document 节点动态覆盖 `--accent` 全局 CSS 变量；
   - 实现了高亮行歌词颜色与主窗口设定、系统暗黑状态的 100% 完美动态平滑同步。

3. **悬浮条控制按钮完全恢复生效**
   - 在主播放器全局上下文 `PlayerContext` 挂载时，新增了对跨窗口 `player-control` 事件的 Tauri 广播监听；
   - 现在，在桌面悬浮歌词条上点击“播放/暂停”、“下一首”、“上一首”等所有交互按钮，系统能瞬间响应并同步切换主窗口的播放状态。

4. **全方位补全页面深色模式支持**
   - 补充并重构了全屏播放器界面（`.full-player-layer`）、右侧播放队列（`.full-queue-card`）、各种输入框和普通统计卡片在深色模式下的 CSS 样式；
   - 彻底修复了原先深色模式下全屏播放器仍呈现白茫茫背景与亮白卡片的问题。现在，当切换到深色/跟随系统深色时，全屏播放器和所有卡片均会完美呈现精致的极夜黑暗黑拟物背景与强调色发光，视觉效果更具科技高级感。
