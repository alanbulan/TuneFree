本次更新继续围绕歌词时间线、桌面歌词同步、播放兼容性和桌面端信息页做稳定性修复：

1. **歌词时间线与多轨歌词重构**
   - 将歌词解析升级为多轨模型，主歌词作为唯一时间锚点，翻译、罗马音、发音和扩展歌词挂载在对应主歌词行下。
   - 移除默认 0.35 秒硬编码提前量，当前行选择默认按真实播放时间计算，避免歌词抢拍或错位。
   - 同时间戳多人/对唱歌词保留为主歌词多行显示，不再误判成翻译。
   - 日语歌曲可同时保留主歌词、罗马音/发音和翻译轨道，减少多轨内容拆成独立 active line 的问题。

2. **桌面歌词同步优化**
   - 桌面歌词窗口改为接收播放快照，并在窗口内用本地时间投影当前播放进度。
   - 主窗口向桌面歌词同步 `playbackRate`、歌词 offset 和发送时间，避免事件延迟与歌词提前量重复叠加。
   - 暂停、恢复、seek 和切歌时会按最新快照重新计算歌词行，降低桌面歌词与播放器内歌词不一致的概率。

3. **音源与播放兼容性修复**
   - NetEase、QQ、GD Studio 歌词获取保留更多可识别轨道，包括翻译、罗马音/发音和 karaoke-like 字段。
   - GD Studio URL 解析现在优先于本地原生解析；GD 返回空链接时再回落到本地解析和跨源兜底。
   - 针对 `NotSupportedError: The element has no supported sources` 增加兼容重试：先切换到无 AudioContext/无 CORS 的播放模式，仍失败时再降级到 128K。
   - 保留离线下载与在线播放的独立兜底逻辑，减少“可下载但在线播放失败”的场景。

4. **桌面 UI 与关于页调整**
   - 修复全屏播放器底部左下角当前歌曲封面在部分歌曲下被压成椭圆的问题，确保封面始终保持圆形。
   - 关于页面按当前实际代码更新功能特性、技术栈和数据源说明，外部链接可正常打开。
   - 调整关于页左右两栏内容密度，减少右侧大面积空白。

5. **验证**
   - 已通过生产构建验证。
   - 已核对 GD Studio `search` / `url` / `lyric` / `pic` 现有接口参数。
   - 已检查本次代码 diff 无空白错误。
