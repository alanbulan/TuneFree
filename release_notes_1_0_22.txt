本次更新重点修复了上一版本中遗留的桌面歌词溢出截断和主界面控制按钮丢失的问题：

1. **修复桌面歌词溢出截断问题**
   - 限制了歌词窗口中 HTML/Body 以及 React 根节点的最大高度为 100% 物理窗口高度，并强行开启溢出裁剪。
   - 优化了歌词滚动容器的伸缩属性（flex-shrink: 1），彻底杜绝了歌词因超出视口在物理窗口边缘被系统强行横向切断、文字只露半截的现象，使得滚动和多行歌词展现更加平滑自然。

2. **修复主窗口顶栏控制按钮丢失**
   - 调整了顶栏的 HTML 节点层级，将快捷主题切换按钮移动到中间的 Flex 容器内，恢复了顶栏原有的 Grid 三列布局。
   - 成功解决了因网格数错位导致右上角“最小化、最大化、关闭”窗口操作按钮被挤至下一行而丢失的严重问题。

3. **完整合入此前版本的所有优化**
   - 优化桌面歌词的硬边描边，字体边缘更清晰。
   - 弃用 emoji 🔒 锁，改用矢量 Lucide 图标。
   - 支持多行歌词智能滚动与磁吸居中。
   - 全面适配并补全了全屏播放器和部分卡片在深色模式下的底色覆盖。
