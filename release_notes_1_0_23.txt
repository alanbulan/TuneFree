本次更新重点重构了桌面歌词实现、补齐主题系统与深色模式，并新增关闭到托盘的桌面生命周期能力：

1. **桌面歌词结构重构与显示优化**
   - 参考 LX Music 的桌面歌词分层思路，将独立歌词页拆分为桥接层、工具栏、歌词舞台与单行渲染组件，避免整段歌词滚动列表在当前行背后产生残影。
   - 优化当前歌词与上下文歌词的渲染策略：当前播放行始终居中突出显示，上下文歌词会根据窗口边界高度动态增加，最高可展示更多歌词上下文。
   - 新增桌面歌词边缘/四角拖拽缩放支持，移除手动“宽/高”按钮，让歌词窗口边界调整更接近原生桌面歌词体验。
   - 修复双语歌词 fallback 被播放进度事件反复清空的问题，翻译歌词只在切歌时重新解析。

2. **主题系统与深色模式整理**
   - 新增共享主题工具，统一主题模式、强调色、歌词字号、字体、桌面歌词开关与锁定状态的读取和应用逻辑。
   - 补齐主窗口与桌面歌词子窗口的主题变量同步，强化深色模式下设置、关于、队列、离线下载、全屏播放器等区域的底色和文字覆盖。
   - 将多个硬编码红色/浅色样式替换为主题 token，使强调色、暗色模式和桌面歌词颜色表现更加一致。

3. **关闭到托盘与应用生命周期管理**
   - 新增“关闭主窗口时”设置项，支持“每次询问 / 最小化到托盘 / 退出应用”。
   - 点击关闭按钮时可选择后台运行或彻底退出，并可记住选择。
   - 新增系统托盘菜单，可从托盘恢复 TuneFree 或彻底退出应用。
   - 统一真正退出路径，确保主应用彻底退出时桌面歌词窗口同步关闭，不再残留透明歌词窗口。

4. **播放与发布稳定性修复**
   - 将可预期的音源不支持/解析失败从开发期 console error 调整为 warning，避免 Next 开发错误遮罩误报。
   - 保留音质 fallback 到 128K 的逻辑，播放失败时仍会提示用户换源或稍后再试。
   - 补齐 Tauri 窗口 resize、聚焦、托盘、事件通信等必要权限和 Rust 侧生命周期处理。
